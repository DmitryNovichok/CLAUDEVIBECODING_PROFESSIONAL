## Обучение

- `learning_content.py`: авторские краткие разборы для каждой темы; существующие полные презентации №1, 3, 5 сохраняются и имеют приоритет.
- `m01`: 10 шагов Python с нуля, 20 задач. Существующие задания m00 не удалены. Все старые ID сохранены.
- Учебная проверка кода на нескольких открытых примерах выполняется в Web Worker в браузере, без запуска ученического кода на сервере. Лимит запуска 5 секунд на пример, загрузки Python 90 секунд. Это самопроверка, не защищённый экзаменационный автогрейдер; зачёт по-прежнему проверяет сервер по ответу.
- Для проверки программирования как навыка нужен отдельный изолированный серверный исполнитель со скрытыми тестами; эта версия его не подменяет браузерной отметкой.
- В уровне показывается одна выбранная задача и навигация по остальным. Положение слайда, последняя тема и задача сохраняются на этом устройстве отдельно для каждого аккаунта.
- Переход в лабораторию переносит код, условие, ввод и файлы задачи. Кнопка возврата сохраняет изменённый код задачи. Свободный черновик лаборатории не заменяется кодом урока.
- Использование подсказки/разбора учитывается сервером. Пометка самостоятельного решения означает отсутствие зарегистрированной помощи до первого верного ответа; это не гарантия отсутствия внешней помощи. Для старых решений способ работы неизвестен.
- Учитель видит отметки помощи при открытии задачи ученика в существующей панели программирования. Старый прогресс и экономика не пересчитываются.

## Три пароля

Пароли и их хеши нельзя помещать в публичный репозиторий. На сервере после копирования кода:

```sh
sudo -u trainer python3 /opt/trainer/tools/set_learning_passwords.py --db /opt/trainer/server_data/trainer.db
```

Ввести новый общий пароль дважды в скрытом приглашении. Команда обновляет `course_pw`, `pyc_pw`, `lab_pw` в одной транзакции с независимыми солями. Она **не** отзывает входы, не меняет коды приглашений, не обнуляет прогресс и не закрывает уже выданный доступ к курсам. Смена общего пароля ограничивает новые входы в разделы, но не отменяет ранее выданные права.

Учителю лаборатории доступны сразу через его учебную учётную запись. Ученику требуется ввести пароль лабораторий один раз. Если `lab_pw` не настроен, сервер не выдаёт доступ и закрывает файл лабораторного Python-исполнителя. Исходный код публичного проекта сам по себе не является секретным материалом; запрет копирования моделей эта защита не обеспечивает.

Скрипт требует существующую базу и не создаёт новую при опечатке в пути. Никаких паролей в аргументах командной строки, логах или инструкции.
