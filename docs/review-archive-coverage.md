# Архивные последовательности и область проверки №27

Проверка относится к конкретным материалам версии 2.74.0. Она не подтверждает
полноту всего №27, всех исторических типов или правильность внешнего банка.
Номера слайдов ниже начинаются с 1; исходная карта использует индексы с 0.

## Разделение актуальной темы и архива

В официальной спецификации ФИПИ-2027 №23 относится к анализу алгоритма
логического исполнителя, а №27 — к этапам анализа данных. Графы из файла
сохранены как `23_old` (внутренний урок 28). Исторические последовательности
в конце урока 27 явно помечены архивом и не обещаны как текущий формат.
Старые идентификаторы классификатора сохранены: они не превращают архив
в актуальное покрытие номера.

Исходники ФИПИ: [пакет демоверсии, спецификации и кодификатора 2027](https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/inf_11_2027.zip),
спецификация, печатные страницы 15–16; демоверсия, страницы 25–26.

`tests/test_course_archive_sequence.py` сравнивает функции опубликованных
слайдов с прямым перебором индексов для всех списков длины 0–4 над алфавитом
−2, −1, 0, 1, 2 и делителей 1, 2, 3, 5, 7. Эталон не использует частоты
остатков или формулу префиксного алгоритма. Отдельно проверяются реальный
входной файл, число строк и ручные ответы. Это два алгоритмических приёма,
а не все возможные задачи на последовательности.

## Разбор ограничения диаметра

Новый слайд 22 содержит шесть энергий 0; 1; 2; 10; 10,5; 11 и условия
K = 2, R = 2. Разность любых двух энергий одного кластера не должна
превосходить R. Разрыв 8 между тройками запрещает смешивать их; оба
внутренних диаметра допустимы. Доказаны единственность двух троек и
центры 1 и 10,5.

Независимый тест перебирает все неупорядоченные разбиения шести объектов
на две непустые группы, проверяет попарные расстояния, затем напрямую
считает стоимости всех кандидатов в центры. Программа слайда проверяет
уже доказанное разбиение этого примера; универсальный алгоритм для
произвольных K и данных не заявляется.

## Проверенные ответы учебного файла частиц

Для `course/data/27/27c.txt` энергии пересчитаны точными рациональными числами
из исходных десятичных записей. Использована теорема о медиане для минимума
суммы модулей разностей, перебор неупорядоченных пар и целочисленный квадратный
корень для масштабированного расстояния. Программы урока используют иной
расчёт на `float`, поэтому это независимая проверка ответа.

- Слайды 14–15: 603 частицы, группы 191, 231, 181 по указанному учебному правилу.
- Слайд 16: Q1 × 10000 → 262490; Q2 × 10000 → 375532.
- Слайды 19–21, задача 2: 120 частиц с признаком I; средняя энергия × 10000 → 130648.
- Нечётность групп дополнена проверкой, что медианная энергия принадлежит
  ровно одной частице: одинаковые энергии иначе могли бы дать несколько центров.

Данные и числовые ответы этих старых примеров сохранены. Плоские кластеры
и весь внешний банк в область этой новой независимой проверки не включены.

## Исправленное объяснение группировки

Код старого учебного примера делит отсортированные энергии там, где разрыв
между соседними значениями превышает 3. Это было явно сказано на одном слайде,
но далее сопоставлялось с форматом демоверсии без достаточного различения.
Теперь правило повторяется в условии задач, а учебный файл обозначен авторским.

В демоверсии ФИПИ-2027 требуется ограничить разность энергий **любых двух**
объектов кластера; заданы K = 4 и R = 2,0, гарантируется единственность.
Цепочка соседних разрывов ≤R не гарантирует это условие: для 0; 1,5; 3
соседи различаются на 1,5, но крайние значения — на 3. Урок теперь явно
объясняет этот контрпример и не рекомендует переносить код учебного разрезания
на другое условие без проверки. Официальная демоверсия не пересчитывалась
этим учебным кодом и не объявляется решённой в данном отчёте.
