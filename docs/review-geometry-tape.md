## Проверка соседних старых примеров и исправления

- №6: пересечение прямоугольников — 483; объединение — 312, только одна
  фигура — 249; граница 6×9 — 30; квадрат 12×12 — 169 с границей и 121 внутри.
- Для треугольника со стороной 12 проверка без вещественных чисел использует
  `x² < 3·min(y,12−y)²` при целых `x>0`, `1≤y≤11`: 56 внутренних точек.
  Ещё 13 точек на вертикальной стороне дают 69 с границей. Для повёрнутого
  квадрата проверка `|x−10|+|y|≤10` даёт 221 точку.
- №12: приписывание единицы слева даёт `2^len(bin(n)[2:]) + n`:
  2025→4073 за 14 тактов, 100→228 за 10. Прибавление единицы даёт
  1011→1100 за 3 такта и 10111→11000 за 4. Инверсия 110100 даёт 001011₂=11;
  замена ZZZZ даёт XXXX за 6 тактов.
- Редактор: независимый посимвольный поиск первого вхождения подтвердил
  `11211` для 203 единиц; ручная цепочка для 13 единиц даёт `221221`.
  В обратной задаче сумма равна `40+2n+30`, поэтому единственное решение — 15.
- Исправлена ошибочная запись пояснения `1 + 1100100 = 11100100₂`:
  это приписывание единицы слева, а не сложение с единицей. Численный ответ
  228 не изменился.
- Обобщённая формула пересечения прямоугольников теперь использует
  `max(0, x2−x1+1) * max(0, y2−y1+1)`, чтобы пустое пересечение давало ноль.
  Ответ исходного примера 483 не изменился.
- Численная геометрическая модель больше не объявляется точным расчётом для
  любых углов и масштабов. Указаны допуск, необходимость отдельно проверять
  спорные граничные точки и предположение замкнутого простого контура у `path`.

## Повторение проверки

```sh
python3 tools/course_6.py
python3 tools/course_12.py
python3 -m unittest discover -s tests -p test_course_gap_geometry_tape.py
python3 -m unittest discover -s tests -p test_course_lessons.py
```

Новый набор содержит десять проверок: соответствие команд вершинам и ответам,
площадь через независимый подсчёт единичных клеток, ориентацию и полуцелые
площади, объединение непрерывных интервалов вместо перечисления единичных
отрезков, повторные обходы, символные инварианты на всех двоичных словах длиной
до семи, чётность длины унарной ленты, граничный пустой ввод и запись на S.
Также проверены прежние геометрические и двоичные примеры независимыми формулами.

Локально: 10/10 новых проверок прошли; штатный исполнитель уроков подтвердил
вывод всех 22 программ этих двух уроков. Совпадение вывода само по себе не
является предметной проверкой — рассуждения приведены выше отдельно.

Не проверены все произвольные фигуры, все программы машины Тьюринга,
педагогическая достаточность курса для каждого ученика и задания внешних банков.
Глобальные `semantic_verified` и `answers_verified` в карте не включаются.
