# Предметная проверка: IPv4 и восстановление из фрагментов

Дата: 17.11.2026. Область: урок `course/13.json`, его генератор
`tools/course_13.py` и добавленный навык `13.frag`. Это проверка конкретных
примеров урока, а не сертификация всего банка №13 или всех форматов КИМ.

## Добавленные материалы

Шесть слайдов добавлены после прежних 19 слайдов. Индексы прежних материалов
не сдвинуты; идентификаторы курса и прогресса не изменены.

| Индекс (от нуля) | Материал |
| --- | --- |
| 19 | IPv4 из фрагментов: дополнительный учебный навык |
| 20 | Четыре октета, допустимые цифры, ведущие нули и единственность |
| 21 | Ручной разбор восстановления `192.168.10.254` |
| 22 | Проверка всех 24 перестановок |
| 23 | Две самостоятельные задачи |
| 24 | Разбор однозначной и неоднозначной задач |

В условиях явно указано: каждый фрагмент используется один раз, символы и
точки не меняются; после сборки нужны четыре числа от 0 до 255, записанные
цифрами 0–9 без ведущих нулей (кроме самого нуля). Правило относится к целому
октету. Поэтому фрагмент `05` допустим внутри октета `205`.

| Фрагменты | Независимо проверенный результат |
| --- | --- |
| А=`8.10.`, Б=`254`, В=`19`, Г=`2.16` | Единственный порядок ВГАБ, адрес `192.168.10.254`. Из 24 порядков шесть заканчиваются точкой; ещё 17 содержат октет больше 255. |
| А=`.2`, Б=`05`, В=`8.24.16`, Г=`12` | Единственный порядок ГВАБ, адрес `128.24.16.205`. |
| А=`1.`, Б=`2.`, В=`3.`, Г=`4` | Шесть порядков: Г должен быть последним, первые три фрагмента переставляются 3! способами. Единственного ответа нет. |

На слайде используется собственная проверка октетов. В тестах независимым
проверяющим служит `ipaddress.IPv4Address`; отдельно проверяются все позиции
октетов, значения 0/255/256, ведущие нули, пустые части, знаки, пробелы,
нелатинские цифры и чрезмерно длинные числа. Проверка не ограничивается
совпадением напечатанного вывода со строкой ответа.

## Исправления прежних материалов

1. «Поиск маски» спрашивал третий байт, а программа и ответ выводили
   `19 255.255.224.0`. Теперь выводится запрошенное число `224`. Независимая
   проверка: среди допустимых значений байта маски только `224` удовлетворяет
   `177 AND mask = 160`.
2. Формула «узлов на два меньше адресов» была безоговорочной. Теперь указано,
   что она применяется, когда отдельно резервируются адрес сети и
   широковещательный; добавлены исключения `/31` и `/32`. Ответы конкретных
   задач для `/21` и `/27` не изменены.
3. Заголовок «Все разновидности задания 13» заменён на «Основные задачи на
   адреса и маски». Дополнительные фрагментные упражнения не объявляются
   обязательным сюжетом КИМ текущего года.
4. В таблицу допустимых байтов маски добавлен отсутствовавший байт
   `00000000 = 0`.

| `10.8.100.50/21` | Последний обычный узел `10.8.103.254`, 2046 узлов | Блок из восьми третьих октетов, 11 битов узла |
| `200.15.100.23/22` | Сеть `200.15.100.0`, сумма 315 | AND по байтам |

Все 12 программ урока (девять прежних и три новых) проверены при сборке.
Восемь тестов `tests/test_course_gap_ip.py` отдельно проверяют численные
результаты, синтаксические границы и неоднозначность новых примеров.

```sh
python3 tools/course_13.py
python3 -m unittest discover -s tests -p 'test_course_gap_ip.py'
```

## Источники и границы

- [Документация Python: ipaddress](https://docs.python.org/3/library/ipaddress.html)
  задаёт строгую строковую запись IPv4 и поведение `hosts()` для `/31` и `/32`.

  адресов `/31` на IPv4-линиях «точка — точка».
