# Предметная проверка: комбинаторика и системы счисления

Дата: 17.11.2026. Релиз исправлений: 2.75.1, база — `1e8d0bd` (2.74.0).
Область: все 21 слайд урока №8 и 19 слайдов урока №14, включая условия,
пояснения, шпаргалки и самостоятельные задачи. Независимо пересчитаны результаты
11 программ первого урока и 12 программ второго. В этих уроках нет вложенных
файлов данных. Нумерация, заголовки и порядок слайдов сохранены.

Формулировки демонстрационных примеров сверены с имевшейся локальной копией
«ИНФ-11 ЕГЭ 2027 ДЕМО.pdf»: №8 и три альтернативные формулировки №14.
Остальные примеры рассматриваются как учебные, без приписывания им статуса
официальной демоверсии. Это не проверка всех заданий банка №8/14 и не
утверждение о полноте обучения всем разновидностям этих номеров.

## Исправленные ошибки

- В демопримере №8 требуется только номер слова. Программа и поле ответа
  теперь выводят `3914`, а слово НААТЕ остаётся в пояснении.
- Для АННА требуется количество **различных** перестановок: ответ `6`.
  Прежний вывод `6 24` смешивал ответ и число перестановок позиций.
- В шпаргалке №8 условие «Без соседей» пропускало `not` перед `any`, поэтому
  фактически выбирало слова с соседними гласными. Отрицание восстановлено.
- В демопримере №14 про неизвестную цифру требуется только частное:
  `276296118`. Найденное `x = 3` перенесено из вывода в пояснение.
- Универсальный перевод `digits(0, b)` возвращал пустой список. Теперь
  возвращает `[0]`; отрицательные числа и основания меньше 2 отклоняются.
  Область функции явно ограничена целыми аргументами.
- В двоичном разборе `2^100 + 2^50 - 1` между старшей единицей и блоком
  из 50 единиц находятся **50**, а не 49 нулей. Количество единиц 51 было верным.
- В примере с двумя неизвестными цифрами два ответа выводятся числами
  `16 9337327`, без оформления Python-кортежа.
- В титульном фрагменте №14 использована допустимая цифра вместо буквального
  `x`, которое `int(..., 22)` не принимает.

Уточнены пределы полного перебора, память длинной арифметики, заданный порядок
алфавита и исключение Е/Ё, сохранение длины слова с начальными буквами нулевого
кода, ограничения `int` и `printable[:b]` основаниями 2–36. Поиск неизвестного
основания показан через полином с обоснованным диапазоном, не через случайное
ограничение возможностей `int`.

## Независимые основания ответов

| Пример | Проверка | Результат |
| --- | --- | --- |

| Ровно одна Ё | `5 · 4^4` | 1280 |
| КАНОЭ без соседних гласных | Единственный шаблон ГСГСГ, `3! · 2!` | 12 |
| Пятизначные восьмеричные числа | `C(5,2)·6^3 − C(4,2)·6^2`; отдельный проход по числам с `oct` | 1944 |
| Чередование КОБУРА | Два шаблона, `2 · 3! · 3!` | 72 |
| АННА | Выбрать две позиции А: `C(4,2)` | 6 |

| Буквенные цифры в системе 32 | Разряды 52–101 равны 31, разряд 51 равен 16 | 51 |
| Две неизвестные цифры | Линейная зависимость от суммы `x+y`, диапазон 0–42; единственная сумма 16, 17 пар цифр | 16 9337327 |
| Основание для записи 123 | `(b+1)^2 = 169`, единственное положительное решение | 12 |
| Практика №14 | Разрядные заимствования; для третьей задачи `(2485+30x) mod 13 = 0` | 97; 28; 6 205; 2 |

Тестовый эталон нормализует разреженные коэффициенты с переносами и заимствованиями,
вместо копирования функции урока, делящей готовое большое число. Комбинаторные
эталоны используют формулы, позиции и числовые ранги вместо повторения того же
перебора слов. Отдельно проверены требуемый формат ответа, нулевое число,
недопустимое основание, начальный нуль и одинаковые буквы.
