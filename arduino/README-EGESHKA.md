# Лаборатория Arduino (MicroLab) в Egeshka

Папка `arduino/` — самостоятельное веб-приложение MicroLab: редактор схем, симулятор Arduino Uno/Nano (AVR8js),
учебное выполнение скетчей и два курса по 36 уроков. Сайт отдаёт его как статические файлы по адресу `/arduino/`.

## Что добавлено при встраивании

- `egeshka.js` и его подключение в `index.html`, заголовок страницы. Остальные файлы приложения не менялись.
  Скрипт пускает в лабораторию только вошедших учеников с доступом к лабораториям и рисует значок возврата на сайт.
- На сервере: `/api/status` отвечает, что компилятора нет. Сборку чужого C++ на сервере не включаем —
  «Собрать HEX» работает только в локальной версии (`source/local/server.py` + Arduino CLI на своём компьютере).

## Лицензия

Приложение распространяется по GPL-2.0 (`LICENSE`), сторонние компоненты и их лицензии — в `licenses.txt`
(AVR8js, RP2040js, Wokwi Elements, Lit, загрузчик Raspberry Pi Pico; исходники загрузчика — `pico-bootrom-source.tar.gz`).
Исходный код приложения, из которого собран `app.js`, лежит в `source/` (сборка: `npm ci && npm run build`).
Это отдельное приложение рядом с сайтом; код самого сайта Egeshka в него не входит.

## Обновление

Заменить файлы приложения новой сборкой (`web/` из архива), вернуть в `index.html` строку
`<script src="egeshka.js"></script>` перед стилями и положить новые исходники в `source/`.
