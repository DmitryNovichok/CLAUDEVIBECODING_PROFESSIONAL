# Лаборатория Arduino (MicroLab) в Egeshka

Папка `arduino/` — самостоятельное веб-приложение MicroLab: редактор схем, симулятор Arduino Uno/Nano (AVR8js),
учебное выполнение скетчей и два курса по 36 уроков. Страница `/arduino/` проверяет вход и доступ к лабораториям на сервере. Исходники и общие ресурсы доступны отдельно.

## Что добавлено при встраивании

- `egeshka.js` запускает приложение только после ответа `/api/me`, показывает повтор при ошибке связи и рисует значок возврата.
- `source/src/account-storage.js` разделяет проекты, черновики, прогресс и учебные пакеты по `sid` ученика.
  Старые общие ключи `microlab.*` остаются в браузере, но автоматически не присваиваются новому ученику: их владелец неизвестен.
  Новые сохранения имеют префикс `egeshka.arduino.<sid>.`. Это локальные данные, не синхронизация с сервером.
- Версии скриптов и стилей Arduino добавляются сервером, как у основной страницы.
- На сервере: `/api/status` отвечает, что компилятора нет. Сборку чужого C++ на сервере не включаем —
  «Собрать HEX» работает только в локальной версии (`source/local/server.py` + Arduino CLI на своём компьютере).

## Лицензия

Приложение распространяется по GPL-2.0 (`LICENSE`), сторонние компоненты и их лицензии — в `licenses.txt`
(AVR8js, RP2040js, Wokwi Elements, Lit, загрузчик Raspberry Pi Pico; исходники загрузчика — `pico-bootrom-source.tar.gz`).
Исходный код приложения, из которого собран `app.js`, лежит в `source/` (сборка: `npm ci && npm run build`).
Это отдельное приложение рядом с сайтом; код самого сайта Egeshka в него не входит.

## Сборка и обновление

Из `arduino/source/` выполнить `npm ci --ignore-scripts && npm run build && npm test`.
Сборка создаёт полный `dist/` для автономной версии, без входа в Egeshka; `npm run package` упаковывает её для локального сервера.
Для сайта скопировать `dist/app.js` в `arduino/app.js`, сохранив интеграционные `index.html` и `egeshka.js`.
CI сверяет этот файл с повторной сборкой и выполняет тесты симулятора, 72 уроков, сохранений и локального сервера.
При деплое обновлять `server.py` и папку `arduino/` вместе; `source/node_modules/` и `source/dist/` в git не входят.
