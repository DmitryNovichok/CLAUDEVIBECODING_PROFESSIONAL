MICROLAB — ЛОКАЛЬНАЯ ВЕРСИЯ

1. Установите Python 3: https://www.python.org/downloads/
2. Распакуйте архив полностью.
3. Windows: Start-Windows.bat
   macOS / Linux: в терминале перейдите в папку и выполните python3 server.py
   macOS: также можно chmod +x Start-Mac.command и запустить файл.
4. Браузер откроется автоматически. Обычно это http://127.0.0.1:8765.
Если порт занят, сервер выберет свободный и покажет адрес в окне.
Учебные примеры и эмуляция готовых прошивок работают без Arduino CLI.
Все статические ресурсы включены; подключение к Интернету для симуляции не требуется.
Проекты хранятся в localStorage браузера. Регулярно экспортируйте JSON.

ПОЛНАЯ КОМПИЛЯЦИЯ C++ ДЛЯ ARDUINO UNO / NANO
Установите Arduino CLI по официальной инструкции:
https://arduino.github.io/arduino-cli/latest/installation/
Проверьте командой arduino-cli version. Команда должна быть доступна из PATH.
Выполните:
  arduino-cli core update-index
  arduino-cli core install arduino:avr
При необходимости установите библиотеки, например:
  arduino-cli lib install "Servo"
  arduino-cli lib install "LiquidCrystal"
  arduino-cli lib install "DHT sensor library"
После этого в лаборатории нажмите «Собрать HEX».
Arduino CLI из стандартной установки Arduino IDE 2 определяется автоматически.
Список библиотек в интерфейсе — записи проекта; их установка выполняется командами выше.
Служба слушает только 127.0.0.1. Компиляция исполняется локально, shell не используется.
Не запускайте локальный компилятор для чужого непроверенного исходного кода.

ЧЕСТНАЯ МАТРИЦА ПОДДЕРЖКИ
- Arduino Uno / Nano: настоящий AVR8js, загрузка Intel HEX, GPIO, таймеры, UART, ADC.
- Arduino API: упрощённое выполнение C++-подобных скетчей, не полная компиляция.
  Поддерживаются setup/loop, переменные, условия, циклы, digitalWrite/Read,
  analogWrite/Read, delay, Serial, millis, map, Servo, LiquidCrystal и DHT API.
  Типы C++ и целочисленная арифметика воспроизводятся не полностью, используется JS.
- Pico: настоящий RP2040js, UF2, Boot ROM B1, GPIO, UART и USB CDC.
  Экспериментально; не гарантируется работа любой MicroPython / CircuitPython прошивки.
- ESP32 / Mega: только графические компоненты. Прошивки не исполняются.
- Обычный Raspberry Pi / Linux: не реализован.
- LED, резистор, кнопка, потенциометр и переключатель: цифровая связность.
- Servo / LCD / DHT / buzzer: модели API в учебном режиме. Протоколы этих модулей
  для HEX/UF2 в текущей версии не реализованы.
- Остальные элементы каталога: только рисунок и точки подключения.
- Нет SPICE / аналогового расчёта токов, I2C/SPI моделей датчиков, Wi-Fi ESP32,
  облачной сборки, совместной работы, GDB интерфейса, полной совместимости Wokwi.
- Провода diagram.json импортируются по концам; маршрут пересчитывается.
- Прошивки в JSON не сохраняются: загрузите их повторно после перезагрузки.

УЧЕБНЫЙ КУРС
В каждом курсе 36 уроков по 45 минут, 9 модулей. План занятий доступен учителю до прохождения заданий. Прогресс курсов считается отдельно. Теория → схема → запуск.
Страница курса позволяет экспортировать прогресс и черновики в JSON и восстановить их на другом устройстве.
Автоматической синхронизации между браузерами нет.

Каждое занятие рассчитано на 45 минут и включает теорию, разобранный пример, классную практику, мини-проект и домашнюю работу. Ответы на домашние задания входят в экспорт прогресса.

КАТАЛОГ КОМПОНЕНТОВ
103 позиции: 25 плат и 78 деталей. Включите «Только с симуляцией» для выбора компонентов занятия.
Пример «Логический инвертор на макетной плате» выводит обе пары состояний в Serial Monitor.
Двойным щелчком откройте свойства датчика и задайте уровень его выхода. Условные обозначения с пометкой «Только схема» можно размещать и соединять. У части обозначений семейства ESP32 доступны только контакты питания.

ОФОРМЛЕНИЕ И УПРАВЛЕНИЕ
Светлый учебный интерфейс: белые округлые карточки, зелёные действия, голубое выделение и сетка уроков с реальным прогрессом. Шрифты IBM Plex включены в архив.
Tab / Shift+Tab — отступ, Ctrl+/ — комментарий, Ctrl+Enter — запуск / стоп.
Щелчок по проводу — выбрать, Delete — удалить, Ctrl+Z — вернуть.
Колесо мыши — масштаб у курсора; кнопка «Показать всю схему» помещает детали в поле.
Ctrl+S сохраняет текущий проект. Кнопка «Экспорт» скачивает JSON.


УЧЁБА БЕЗ РЕГИСТРАЦИИ
Курсы и лаборатория доступны сразу. Прогресс хранится в текущем браузере.
Для переноса используйте «Сохранить прогресс» в курсе, «Экспорт» в лаборатории.
В разделе «Работа с учителем» можно скачать задание, открыть работу ученика
и вернуть файл с отзывом. Автоматической отправки файлов нет.
Учитель может скачать журнал вместе с классами и работами, затем открыть
его на другом компьютере через «Открыть учебный файл».
Не удаляйте данные браузера без резервной копии.
