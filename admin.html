Прогресс курса

Ученики, которые открыли курс паролем. Прогресс урока: 30% — презентация (докуда долистал), 70% — решённые задания пяти подборок. Нажмите на ученика — увидите каждое задание: решено, с ошибкой, не начато.

Курс «Программирование для ЕГЭ»

Закрытый курс — как раздел «Курс»: ученик попадает в него только по паролю курса. Нажмите на ученика — увидите каждую задачу: решена, есть неверные попытки, не начата; по клику — его код.

Пароль курса

Курс программирования у учеников открывается по этому паролю. Ученик вводит его один раз. Новый пароль действует для новых входов; «Закрыть всем» снова попросит пароль у всех; «Выключить курс» сбросит пароль и закроет курс у всех.

Статистика сайта

Цифры по всему тренажёру, у всех учителей. Имён чужих учеников здесь нет — только количество. Посетители считаются обезличенно: адреса не хранятся. Учительские аккаунты в цифры учеников не входят.

Учителя

У каждого учителя свой логин, пароль и код приглашения. Ученик, который зарегистрировался по коду учителя, попадает к нему. Каждый учитель — и главный тоже — видит только своих учеников, классы, подборки и ленту. По всему сайту у главного — вкладка «Статистика сайта».

Как ученикам открыть тренажёр

Адрес для учеников:

Если открываете панель по адресу localhost, ученикам нужен адрес этого компьютера в сети — он напечатан в окне сервера («Для учеников в сети»).

Авторские задания

Задания без автора — с экзаменов и из ФИПИ: демоверсии, апробации, основные и досрочные волны, ЕГКР. Авторские — составленные преподавателями и школами (Джобс, /dev/inf, Danov, Статград и др.): они часто сложнее и не всегда похожи на настоящий экзамен.

Пароль курса

Раздел «Курс» у учеников открывается по этому паролю. Ученик вводит его один раз. Новый пароль действует для новых входов; «Закрыть всем» снова попросит пароль у всех.
