# Обновление 2.29.1

Обновлять вместе все файлы Python, HTML, JavaScript и CSS в корне проекта,
включая `auth.py`, `economy.py`, `together.py`, `reset.html` и `admin-theme.css`.
`app.js` уже собран. Базы, журналы и `server_data` из архива не копировать.

Для писем восстановления нужны настроенный SMTP и постоянный публичный адрес
сайта: `SITE_URL` в существующем `/opt/trainer/server_data/private_config.json`
или переменная окружения `EGE_SITE_URL`. Значение — полный адрес сайта с
`https://`, без завершающего пути, параметров и данных входа. Адрес из заголовка
посетителя для ссылок восстановления больше не используется.

Письма восстановления, запрошенные до этого обновления, нужно запросить заново.
Обычные входы сохраняются при обновлении; когда пользователь восстанавливает
пароль, закрываются входы только его аккаунта, включая соединения «Вместе».

Перед обновлением сохранить частные настройки командой `deploy/preserve_private.py`
и сделать резервную копию через `deploy/backup.sh`. После копирования файлов
перезапустить `ege-trainer`, проверить `/api/ping` и версию в `changelog.js`.
В браузере обновить страницу: Ctrl+Shift+R, на Mac — Cmd+Shift+R.
