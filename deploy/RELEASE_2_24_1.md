# Исправления 2.24.1

Перед обновлением сделайте копию скриптом `deploy/backup.sh`. Первый запуск автоматически добавит
историю сохранений кода и поля автосохранения экзамена. Существующие решения переносятся один раз.
Если прежняя версия уже перезаписала код после сдачи работы, восстановить его исходный вид можно
только из старой резервной копии. Архив больше не подставляет более позднюю программу.

Новые варианты ЕГЭ сохраняют ответы на сервере во время решения. После 3 ч 55 мин принимаются
только ответы, полученные сервером до окончания времени. При потере связи ученик видит сообщение
с просьбой восстановить её до конца варианта. Варианты, начатые до обновления, завершаются один раз
по прежнему протоколу, чтобы обновление не обнулило работу уже открытых вкладок.

Старые аукционы с несколькими ведущими ставками проверяются при завершении. Если покупка превысит
лимит владения, подарок остаётся продавцу, а вся замороженная сумма возвращается покупателю.
Новые ставки резервируют место в лимите. Формулы изменения цен и курса от активности учеников сохранены.

Обновление сохраняет активные входы и коды приглашения.
